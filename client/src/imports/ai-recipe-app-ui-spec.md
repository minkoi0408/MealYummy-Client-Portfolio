🎨 PROMPT THIẾT KẾ UI CHO FIGMA AI

Thiết kế UI cho một Web App hỗ trợ gợi ý món ăn bằng AI.
Chỉ thiết kế giao diện cơ bản (MVP), tập trung vào layout rõ ràng và hệ thống component.

1️⃣ Phong cách thiết kế

Modern, Clean, Minimal

Không sử dụng hình ảnh món ăn

Tông màu chính: xanh lá nhạt hoặc xanh dương nhạt (cảm giác sức khỏe)

Nhiều khoảng trắng

Border radius mềm (8px–12px)

Bóng đổ nhẹ cho card

Font sans-serif hiện đại

Thiết kế desktop trước (1440px)

2️⃣ Thiết kế hệ thống Design System trước

Tạo:

🎨 Color Palette

Primary

Secondary

Background

Surface

Text Primary

Text Secondary

Border

Error

Success

🔘 Components cần tạo

Button (Primary / Secondary / Outline / Disabled)

Input field

Textarea

Dropdown

Card

Sidebar item

Navbar

Statistic card

Modal cơ bản

Tất cả component phải reusable và có auto layout.

3️⃣ Các màn hình cần thiết kế (5 màn hình chính)
🟢 1. Landing Page

Layout:

Header:

Logo trái

Login / Register phải

Hero Section:

Heading lớn:
“Hôm nay ăn gì? AI sẽ giúp bạn quyết định.”

Mô tả ngắn

1 ô input demo

Nút lớn: “Gợi ý ngay”

Footer đơn giản

Thiết kế cân đối, hiện đại.

🟢 2. Login / Register Page

Card nằm giữa màn hình

Input:

Email

Password

Nút Primary: Đăng nhập

Link nhỏ: Quên mật khẩu

Tab chuyển Login / Register

🟢 3. Main App – Trang nhập nhu cầu

Layout 2 cột:

Cột trái (Form):

Textarea lớn: “Bạn muốn ăn gì hôm nay?”

Input:

Ngân sách

Số người

Thời gian nấu

Dropdown: Chế độ ăn

Button lớn: “Gợi ý món”

Cột phải:

Khu vực hiển thị kết quả (placeholder card)

🟢 4. Trang hiển thị kết quả

Hiển thị danh sách card dọc.

Mỗi card gồm:

Tên món (Heading)

Thông tin nhỏ:

Calo

Giá

Thời gian nấu

Mô tả / Lý do đề xuất

Button nhỏ:

Lưu món

Thay món khác

Không dùng hình ảnh.

🟢 5. Dashboard

Layout có Sidebar bên trái:

Sidebar:

Trang chủ

Lập thực đơn

Món đã lưu

Hồ sơ

Cài đặt

Main content:

2–3 Statistic Cards

1 biểu đồ đơn giản (placeholder)

4️⃣ Yêu cầu bổ sung

Sử dụng Auto Layout toàn bộ

Thiết kế theo 8px spacing system

Tạo grid 12 cột cho desktop

Có trạng thái hover / active cho button

Tạo variant cho component

5️⃣ Mục tiêu

Thiết kế khung giao diện cơ bản để phát triển MVP trước.
Các chức năng nâng cao sẽ thêm sau.
